# Dota 2 виджет для OBS

Показывает **MMR**, **ранг (медаль + дивизион)** и **последние 10 игр** в виде `W`/`L`.
Данные — из Steam через [OpenDota](https://www.opendota.com) (OpenDota читает публичный матчлог Steam-профиля).
Обновление — само, раз в 30 минут (интервал настраивается).

Один файл, без сборки и зависимостей: `index.html`.

> **Живой пример:** https://afteronchik.github.io/dota2-obs-widget/index.html?id=76561199182854521
> (это же можно вставить прямо в OBS → Источник → Браузер → URL, тогда файлы на компьютере не нужны вовсе)

---

## Быстрый старт (OBS)

### Вариант 1 — по ссылке (проще всего, ничего не скачивать)

1. OBS → **Источник → Браузер**.
2. **URL:** `https://afteronchik.github.io/dota2-obs-widget/index.html?id=ВАШ_STEAM_ID`
3. Размер: **640 × 260**.

### Вариант 2 — локальный файл

1. Скачайте папку с файлами (или `git clone https://github.com/Afteronchik/dota2-obs-widget`) куда-нибудь, например `C:\obs\dota2-widget`.
2. В OBS добавьте **Источник → Браузер** (Browser).
3. Тип источника: **Локальный файл** → выберите `dota2-widget\index.html`.
4. В поле **URL-параметры** дописывать нельзя, поэтому проще выбрать **URL** и вписать:
   ```
   file:///C:/obs/dota2-widget/index.html?id=ВАШ_STEAM_ID
   ```
   (или `http://127.0.0.1:8787/index.html?id=...` — см. «Если запросы не работают», ниже)
5. Размер источника: **640 × 260** (обычно этого достаточно), «Обновлять браузер при изменении настроек источника» — включить.

Виджет сразу покажет медаль, MMR и полоску из последних игр.

### Как узнать свой Steam ID

Подойдёт любой вариант в параметре `id`:

| Что можно указать | Пример |
|---|---|
| 32-битный account ID | `611294396` |
| 64-битный SteamID | `76561199182854521` |
| Ссылка на профиль | `https://steamcommunity.com/id/nobrooh/` |
| Ник / vanity-имя | `.` |

32-битный ID удобнее всего взять из адресной строки своего профиля на OpenDota.

### Обязательное условие

Профиль Steam должен быть **публичным** (Steam → Настройки профиля → Конфиденциальность → «Мой профиль: общедоступный»),
иначе ни OpenDota, ни виджет не увидят матчи. Новые игры появляются у OpenDota с задержкой до ~15 минут — это нормально.

## Настройки

### 1. Через URL (рекомендуется для OBS)

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `id` | — | Steam ID / ник / ссылка на профиль |
| `refresh` | `30` | Интервал автообновления, минуты |
| `matches` | `10` | Сколько игр показывать (1–20) |
| `lang` | `ru` | `ru` или `en` |
| `bg` | `dark` | `dark` — карточка с фоном, `transparent` — прозрачный фон (для оверлея) |
| `modes` | `all` | `all` · `ranked` (только рейтинговые) · `ranked_no_turbo` · `turbo` |
| `size` | `1` | Множитель всех размеров (шрифт, медаль, чипы) |
| `accent` | красный | Цвет акцента, например `#3aa0ff` |
| `names` | — | Свои названия рангов через запятую: `Без ранга, Рекрут, Страж, …` |
| `showMmr` `showAvatar` `showHero` `showKda` `showDelta` `showApprox` `showSummary` `bar` `newest` `showCountdown` | `1` | Включить/выключить элементы (`0`/`1`) |
| `hideGear` | `0` | `1` — полностью спрятать шестерёнку настроек |
| `proxy` | — | Префикс CORS-прокси, если запросы блокируются |
| `mock` | `0` | `1` — демо-данные без сети (подобрать размер и вид) |

Пример:

```
file:///C:/obs/dota2-widget/index.html?id=292938308&refresh=30&matches=10&bg=transparent&modes=ranked&showKda=0
```

### 2. Через шестерёнку ⚙

Шестерёнка появляется **только при наведении мыши**, поэтому в стриме её не видно (в OBS мышь в браузер-источник по умолчанию не передаётся).
Там же — кнопка «Скопировать URL»: собирает готовую ссылку со всеми настройками, её и вставьте в OBS. Параметры из URL всегда важнее сохранённых.

## Что именно показывает виджет

- **MMR** — оценка OpenDota (`computed_mmr`): Valve больше не отдаёт точный MMR через публичные API, поэтому рядом стоит знак `≈`. Стрелка ниже показывает изменение с прошлого обновления, а также дельту за 24 часа (виджет хранит историю локально).
- **Ранг** — медаль и дивизион из публичных данных профиля (те же значения, что показывает opendota.com). Для Immortal дополнительно показывается глобальная позиция (`#N`).
- **Последние N игр** — слева направо от старых к новым, `W`/`L`, иконка героя и KDA; последняя игра подсвечена. Ниже — винрейт, счёт `W/L` и текущая серия.
- **Статус** — когда данные обновлены и сколько осталось до следующего обновления.

Если OpenDota недоступна, виджет продолжает показывать последние сохранённые данные и подсвечивает это жёлтым/красным индикатором.

## Если запросы не работают

Обычно работает и из `file://` (OpenDota отвечает `Access-Control-Allow-Origin: null`). Если в вашем OBS запросы всё же блокируются:

**Вариант А — мини-сервер** (нужен Node.js):

```
cd C:\obs\dota2-widget
node serve.mjs
```

Сервер поднимется на `http://127.0.0.1:8787`. Если порт уже занят, он сам возьмёт следующий свободный и напишет верный адрес в консоли (порт можно задать и вручную: `node serve.mjs 9000`).

и в OBS URL: `http://127.0.0.1:8787/index.html?id=ВАШ_STEAM_ID`
(чтобы сервер не выключался вместе с консолью, запускайте его через `start /min node serve.mjs` или добавьте в автозагрузку).

**Вариант Б — публичный CORS-прокси**: добавьте `&proxy=https://corsproxy.io/?` к URL.

## Частые проблемы

| Симптом | Причина / решение |
|---|---|
| «Профиль закрыт или игрок не найден» | Профиль не публичный, или ник совпал с чужим — укажите числовой Steam ID |
| Ранг есть, игр нет | Матчлог закрыт, или последние игры были не в обычном режиме; попробуйте `modes=all` |
| MMR не сходится с клиентом | Это оценка, а не точное значение Valve |
| Данные не обновляются | В OBS выключен «Shutdown source when not visible» + источник скрыт; или увеличьте `refresh` |
| Виджет огромный/маленький | Подберите размер источника (640×260) и `size` |
